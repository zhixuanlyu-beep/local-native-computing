# Composition arguments for the abstract IC calculus

This document gives mathematical arguments about finite port graphs. It does not turn the Python implementation or the experiment archive into a formally verified theorem prover. The executable environment and commands are in [COMPOSITION_CONTRACTS.md](COMPOSITION_CONTRACTS.md); all empirical coverage and measurements are in [claim ledger §T](CLAIM_LEDGER.md#t-composition-arguments-and-schedule-evidence-e_composition).

## Model and hypotheses

A graph has cells with one principal port and an ordered finite list of auxiliary ports, uniquely labeled external endpoints, a perfect matching of distinct endpoints, and a nonnegative count of closed wire cycles. Cell names are irrelevant up to bijective renaming; kinds, port indices, external labels, and wire-cycle counts are preserved. A rule replaces two cells joined at their principal ports by a finite graph with exactly the same ordered auxiliary interface. Fresh cells are disjoint from all surviving cells. The IC rules are exactly the gamma/gamma crossed annihilation, delta/delta straight annihilation, epsilon/epsilon annihilation, gamma/epsilon and delta/epsilon erasure, and gamma/delta commutation in `ic_primitive_port_verifier.RULES`.

Gluing identifies matching interface endpoints, then replaces each path through those degree-two connectors by a wire between its surviving endpoints. A component with no surviving endpoint contributes one closed wire cycle. This definition includes auxiliary wires that run back into the redex and wires between different redexes. It does not silently discard components.

The arguments below assume this abstract definition. Applying them to the executable reducer additionally assumes that its allocation, matching, splicing, and cycle accounting implement that definition. Finite audits and raw replays test that assumption on their recorded inputs; they do not prove it for every Python state. Compiler results also assume the specified fixed templates and independently checked local witnesses, as stated below.

## Gluing, contextual lifting, and commuting reductions

**Gluing lemma.** For disjoint graph interiors with matching interfaces, resolving connectors in either order gives the same graph up to fresh-cell renaming, including its closed wire cycles.

**Argument.** Before any connector is resolved, each connector has degree two and each surviving endpoint degree one. Every connected component of the wire relation is therefore a path with two surviving endpoints, or a cycle with none. Eliminating a subset of degree-two vertices changes neither the endpoints of a path nor whether the component is a cycle. Each cycle is recorded once when its last connector is resolved. Existing wire cycles add independently. Thus both elimination orders resolve precisely the same components.

**Contextual lifting lemma.** If `L -> R` is one internal rewrite, then any legal boundary gluing with a graph context gives `C[L] -> C[R]`. Consequently, every finite internal trace `L ->* R` lifts to a trace of the same length and rule labels, using an injective fresh-name map at every step.

**Argument.** External gluing cannot change the principal-to-principal wire inside the chosen redex. Replace its cells by the same fresh rule interior. The gluing lemma identifies the resulting boundary splice with the splice in `C[R]`. Induct on the trace length, extending the name map to the freshly allocated cells and deleting consumed names. The map is essential: copying old numerical IDs into a larger context does not identify the same cells. The context can have other redexes; the lifted trace deliberately leaves those redexes unchosen. This proves an internal trace prefix, not that an arbitrary context terminates or observes an equivalent value.

**Strict diamond lemma.** Two different current redexes have residuals after one another's rewrites, and reducing those residuals gives the same graph up to fresh names. The two paths have the same two rule labels in opposite order.

**Argument.** A cell has only one principal port, so different current redexes have disjoint cells. Each principal port of the second redex is already matched to its partner; it cannot be an auxiliary-context endpoint of the first redex. The first rewrite therefore neither removes that cell pair nor changes its principal wire or kinds. Both residuals exist. Simultaneously replace the two disjoint cell pairs with disjoint fresh right-hand sides. The gluing lemma shows that either sequential order gives this simultaneous replacement, even when their auxiliary interfaces are wired to each other and even when a closed wire cycle results. Rule labels are unchanged because each residual keeps its original two cell kinds.

**Uniform normalization corollary.** If a graph has one finite normalizing reduction of length `k`, every maximal abstract reduction from that same graph is finite, reaches that normal form up to fresh names, has length `k`, and uses the same multiset of primitive rule labels. Existence of that finite normalizing trace is a hypothesis, not a general termination theorem. No fairness assumption is needed.

**Argument.** Induct on `k`. For `k=0` no redex exists. For `k>0`, let the known first step be `r`. Any other first choice `s` either is `r`, or forms the strict diamond above. Apply the induction hypothesis to the state after `r`: its residual `s` must lead to the same terminal state in `k-2` further steps. The state after `s` therefore has a normalizing reduction of length `k-1` through residual `r`, so induction applies there as well. For `k=1`, a distinct persistent redex would contradict that the state after `r` is normal. The same induction with formal sums of rule labels proves the multiset statement. Hence no alternate infinite reduction is possible.

This is the standard interaction-net strong-confluence argument: see Lafont, *Interaction Combinators*, Proposition 1 and the subsequent normalization discussion, [DOI](https://doi.org/10.1006/inco.1997.2643), and Mazza, *Interaction Nets: Semantics and Concurrent Extensions*, Proposition 1.2 and the following discussion ([author-hosted thesis, PDF page 37](https://lipn.univ-paris13.fr/~mazza/papers/Thesis.pdf#page=37)). It is a statement about the abstract calculus. It is not an assertion that every schedule was explored in a large archived Python network.

## Macro and principal-package lemmas

**Frame cancellation.** With the repository's logical leaf order, connecting `M_n` to `M_n*` yields the corresponding `n` identity wires. For `n=0` the epsilon pair disappears in one interaction and leaves no wire cycle. For `n=1` the macros are wires and require no interaction. For `n>=2` cancellation takes `n-1` gamma/gamma interactions.

**Argument.** For `n>=2`, the top gamma cells have mirrored child order. Crossed annihilation connects each child subtree to its matching mirrored subtree. Induction removes each internal gamma pair and preserves each leaf index. There are `n-1` internal cells per tree. The wire and epsilon definitions give the base cases directly. Contextual lifting permits the leaves to be connected to any legal surrounding graph; their subsequent behavior is a separate obligation.

**Selection.** Connect an ordered menu to the matching selector whose chosen leaf is the output and whose other leaves are epsilon. Frame cancellation connects the chosen payload to the output and the other payload roots to epsilon. If the discarded payloads are principal packages, the erasure lemma below removes them completely. Thus selection preserves the chosen complete package, including its internal port wiring, rather than just its decoded value.

A **principal package** is a finite reduced graph with one external endpoint attached to a principal port, no closed wire cycles, and a principal-parent path from every cell to that root. Here a parent path follows the wire at a cell's principal port into its parent's auxiliary port. This condition excludes disconnected components and vicious principal cycles. It is stronger than the absence of active pairs and is checked by `validate_package`.

Let a package contain `n` cells. Its principal-parent edges form a rooted tree: each non-root cell has exactly one parent, and the package condition excludes directed cycles. There are `n-1` principal-to-auxiliary internal wires. Every remaining internal wire joins two auxiliary ports. Write `w` for their count. If `a` is the sum of cell arities, then `a=(n-1)+2w`, so `w=(a-n+1)/2`. The variable `w` does not count all internal wires.

**Delta-free copying.** A delta at the root of a principal package containing only gamma and epsilon produces two disjoint isomorphic copies, with the two declared output labels and no extra components or cycles. There is a reduction using `n+w` interactions.

**Argument.** Process the package along its principal-parent tree. A delta/gamma interaction creates the two output gamma cells and sends a delta to each child auxiliary wire; delta/epsilon gives one epsilon at each output. Thus each original cell is processed once. An auxiliary-to-auxiliary package wire receives a delta at each end. The resulting delta/delta interaction reconnects each copy's corresponding auxiliary ports by the straight annihilation rule. Each such wire is processed once. These are all original cells and all non-tree wires, so the work is `n+w`. The two copies have distinct fresh cells, preserve every ordered port, and have no leftover frontier. The argument fails for a delta cell in the payload: delta/delta annihilates it rather than constructing two delta cells. The executable negative witness preserves this precondition failure.

**Erasure.** An epsilon at the root of any principal package over gamma, delta, and epsilon removes the entire package, including all wiring, without leaving a component or wire cycle. There is a reduction using `n+w` interactions.

**Argument.** Process each original cell once along the same parent tree. Gamma/epsilon and delta/epsilon put erasers at the auxiliary wires; epsilon/epsilon removes a leaf. Each auxiliary-to-auxiliary original wire eventually joins two erasers and needs one further epsilon/epsilon interaction. There are no unprocessed parent cycles or detached components by the package hypothesis. The complete frontier is consumed in `n+w` steps. These are existence arguments for explicit traces; the uniform normalization corollary then applies in the abstract calculus.

**Package decoding.** For a valid package `pi`, the literal `encode_package(pi)` is delta-free, and `D(!pi)` reduces to an exact copy of `pi`. If `pi` has `d>0` delta cells, one decoding trace has length `3d`; if `d=0`, its length is six.

**Argument.** Encoding cuts each original delta into its three ordered ports and stores the three groups and the original root in a four-slot gamma frame. No source rule or task result is consulted. The decoder cancels that outer frame in three interactions. For `d>0`, its single delta passes through the principal-cut group, creating the `d` restored delta cells by `d-1` gamma/delta interactions. The two copied gamma trees cancel the mirrored auxiliary-cut groups in `2(d-1)` interactions by frame cancellation. The restored delta ports are exactly the three ordered cut lists, so all original wires and the root are restored. Total work is `3+(d-1)+2(d-1)=3d`. For `d=0`, the empty groups are epsilon: the decoder delta meets one epsilon and its two resulting erasers meet the other two, adding three interactions after outer-frame cancellation. Original gamma/epsilon cells and their remaining wires persist in both cases.

Since the code is itself a delta-free principal package, one may first copy it and then decode each product. If its size and auxiliary-pair count are `n_code,w_code`, a constructive two-output trace costs `n_code+w_code+2*decode_cost(pi)`. Contextual lifting composes those traces. This does not say that absence of code erases a whole source-symbol extension; that separate inference is already refuted by the bridge evidence.

## Source-rule replacement and finite forward simulation

Let `J` be the fixed compiler. It maps each source cell kind to one reduced primitive template with ordered source ports, then glues those ports exactly as specified by the source adjacency. Its code package and column definitions are fixed; source rules are used during construction, never as runtime rewrite operations.

The source domain here is the finite complete adjacency representation accepted by `compiler.compile`, with the stated source alphabet and exposed boundaries. It does not include a separate counter of standalone source wire cycles. Source gluing statements require their result to remain in that domain. On the primitive side, all generated wire cycles remain part of graph equality and resource records. The declared typed programs and constructor results satisfy this domain restriction.

**Compiler gluing lemma.** If a source graph is obtained by gluing source components, `J` of that graph equals the gluing of their compiled templates, up to fresh-cell names and private wire proxies.

**Argument.** Both constructions allocate the same template once per source cell and connect the same ordered exposed ports. Eliminating private one-port construction proxies resolves the same paths. The gluing lemma makes the order of those connections irrelevant. No reductions or expected source answers are used.

**Local-witness hypothesis.** For every allowed source rule `A-B : L -> R`, a fixed finite primitive trace takes `J(L)` to the complete graph `J(R)` with matching ordered boundary labels, all components, and wire-cycle count. `ic_rule_trace_lifting.py` binds the existing frozen table and witnesses, rather than replacing them with new expected rules. Their executable validity is finite evidence, not a proof for arbitrary compiler implementations.

**Forward-simulation theorem, conditional on that hypothesis and faithful primitive rewriting.** If a well-formed finite source graph has a finite source reduction `S ->* F`, then `J(S) ->* J(F)` by primitive interactions. The native trace is the concatenation of the local witnesses lifted through their current source contexts.

**Argument.** For one source step, decompose the graph into the rule's cells and its wire context. Compiler gluing identifies their compilation with `C[J(L)]`. Lift the fixed local trace to `C[J(R)]`, which compiler gluing identifies with the compiled next source state. Induct on the finite source trace. At every step choose fresh target names through the current embedding. This is a reduction in one evolving abstract graph; it does not require a host reset between source steps. The executable full-program experiments independently run primitive pair selection from their initial graph instead of invoking this theorem as a macro operation.

For the source type table, a well-typed principal cut is an N input (`DUP`, `ERA`, `INIT`, `CMP`, `CMP0`, or `CMPS`) against `Z` or `S`, or a T input `GATE` against `EQ`, `GT`, or `LT`. Those are exactly the supplied source rule pairs. Hence a well-typed source normal form has no principal cut. Individual target templates are reduced; an exposed source principal is a physical delta principal, whereas an exposed auxiliary is a gamma auxiliary. Gluing a source graph with no principal cut therefore creates no target active pair. Thus `J(F)` is a primitive normal form for these well-typed source normal forms.

Combining this fact, forward simulation, and uniform normalization gives a conditional all-schedule theorem for the **abstract compiled graph** whenever the source trace terminates. The finite schedule experiments separately test the concrete implementation on their selected inputs. The statement supplies neither a source termination theorem for every graph, reverse simulation, divergence reflection, nor arbitrary observational-context equivalence.

## Structural readout and resources

**Readout lemma for finite constructor output forests.** Suppose a source normal form consists only of the declared finite `Z/S`, `SQ/BR`, and `EQ/GT/LT` constructor outputs rooted at uniquely labeled output boundaries. Suppose each compiler template has the complete recognized ordered-port footprint and distinct source kinds have distinct recognized templates. Matching the complete footprints in `J(F)` reconstructs `F` up to source-cell names. Consequently, unary and result-constructor readout agrees with the source output.

**Argument.** Start at each labeled output boundary and match its root's entire template, with port order retained. The hypotheses identify its source kind uniquely. Follow each exposed child port and repeat down the finite constructor tree. Induction reconstructs all source constructors and wires. Different output components remain disjoint; aliases or reused target footprint cells are rejected. Require the union of matched footprints to cover all target cells and require the wire-cycle count to be zero. These coverage conditions reject garbage that a decoded scalar alone would miss. The claim is restricted to constructor output forests; it is not an injectivity theorem for the decoder on every cyclic or closed source net. The Python footprint recognizer's conformance remains an implementation obligation.

Let `s(A)` be the cell size of the fixed template for source kind `A`. A source graph's compiled size is `sum_A count(A)*s(A)`. For a source trace whose successive rule witnesses have lengths `t_i`, the constructive native trace has length `sum_i t_i` and primitive rule census equal to the sum of the witness censuses. The uniform normalization corollary transfers those counts to any normalization of that abstract compiled graph. The executable report compares these independent predictions with actual reductions under each declared policy.

For source step `i` replacing `A-B`, let `I_i` be the compiled size before the step and `p_i` the local witness's peak cells including its initial state. The lifted staged trace has peak at most

`max_i (I_i - s(A) - s(B) + p_i)`.

The exterior cells are constant while that witness is replayed; fresh local allocations do not add exterior cells. For an empty source trace use the compiled initial size. This is a constructive bound for that staged trace. It is not a bound on every interleaving of interior and context interactions.

For any measured primitive trace with initial size `I`, let `c_r` be that trace's count of rule `r` and `a_r` its right-hand-side cell count. Then terminal cells equal `I + sum_r c_r*(a_r-2)`, runtime allocations equal `sum_r c_r*a_r`, and total symbolic cells ever allocated equal their sum with `I`. Only gamma/delta has positive cell change, equal to two, so that trace's atomic-state peak is at most `I + 2*c_gd`. Equal lengths and rule censuses do not force equal peaks: different orders can accumulate positive changes before negative changes are performed.

For disjoint compiled components, color each initial cell by its component and inherit that color on a rewrite's fresh cells. No wire crosses components, so each redex has one color. Deleting steps of other colors projects any global trace into a valid trace of that component. Work is the sum of projected work. At each global state the live count is the sum of component live counts, so its peak is bounded by the sum of the **projected traces'** peaks. These need not equal peaks obtained by running each component separately under a policy with different name or tie ordering.

All these resource quantities count symbolic cells at atomic IC states. They omit interpreter objects, transient splicing data, host evaluation/readout costs, and physical inventories. They establish no optimality or benefit from reuse. M2 constructor readiness is not a whole-network quiescence certificate, and M1 archive reconstruction remains an offline research operation.
